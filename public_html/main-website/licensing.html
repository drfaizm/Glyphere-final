End User License Agreement (EULA)

1. Grant of License

Upon receipt of payment in full, Glyphere grants you a non-exclusive, non-transferable, perpetual license to install and use the digital typeface files on the specified number of workstations matching your checkout selection.

2. Permitted Uses

You may use the licensed fonts to create static graphics, digital presentations, vector designs (logos, corporate identifiers), marketing materials, printed layout items, and other graphic works for personal and commercial client projects.

3. Restrictions

  • You may NOT edit, decompile, modify, or regenerate the font file source code (.otf, .ttf).
  • You may NOT share, lease, sublicense, resell, or distribute the licensed files to third parties.
  • You may NOT embed the desktop font files in website code or software applications without purchasing the matching Web or App license tier.

4. Termination

This license agreement terminates immediately if you breach any of the clauses outlined. Upon termination, you must delete and uninstall all digital copies of the typeface from your workstations.

1. Grant of Web License

Glyphere grants you a non-exclusive, non-transferable, perpetual license to host and embed the web font files (.woff, .woff2) on the domain specified at the time of purchase, supporting website traffic up to your selected pageviews-per-month threshold.

2. Permitted Embedding

Embedding is restricted to the browser self-hosting technique using the CSS @font-face selector. The font files must be secured on your own domain hosting environment.

3. Security & Restrictions

  • You must take reasonable technical steps to ensure third parties cannot download the raw web font files.
  • Using the web font files as an asset inside interactive, customizable SaaS engines (e.g. online custom card templates, design tools) is strictly prohibited under standard licenses and requires a custom SaaS integration license.
  • Hotlinking directly to Glyphere files is not permitted.

1. App/ePub Embedding Rights

Glyphere grants you a non-exclusive, non-transferable license to compile and bundle the digital font files (.ttf, .otf, .woff) directly inside the resource bundle of your native mobile application, electronic publication (ePub), or desktop executable software program.

2. Unlimited Updates

The license is valid globally for standard operating systems (iOS, Android, macOS, Windows, Linux) and applies for the lifetime of the application, including future software version updates and releases.

3. Critical Restrictions

  • The font files must be stored securely inside the application package such that end users cannot extract the raw fonts from the installed app files.
  • Interactive typing templates where the font is editable and the system outputs static custom user designs require an upgrade.
